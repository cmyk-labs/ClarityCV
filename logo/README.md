# ClarityCV logo assets

The approved identity combines the ClarityCV wordmark with a refined document symbol.

- `claritycv-logo.svg`: primary horizontal lockup.
- `claritycv-logo-dark.svg`: horizontal lockup for dark backgrounds.
- `claritycv-logo-mono.svg`: one-color fallback.
- `claritycv-mark.svg`: standalone mark for avatars and small placements.
- `preview.svg`: primary, dark-background, small-size, and monochrome checks.

The mark uses a light page outline, a warm folded corner, and three aligned content strokes. The core logo contains only the English brand name, uses two colors, and keeps the mark separate from the wordmark for flexible use.
