# 照片目录

如需在简历中显示照片，请将自己的照片放在此目录，并在 `claritycv.tex` 中写：

```tex
\resumeheader[photo={images/avatar.jpg}]{姓名}{联系信息}
```

仓库中的 `placeholder-id-photo-transparent.png` 是 AI 生成并完成背景分离的透明底虚构人物证件照，仅用于展示模板效果，不对应任何真实个人。

`logo-stellar-tech.png` 与 `logo-cloud-lab.png` 是透明背景的虚构公司 Logo，可用于 `\resumebanner` 色块示例。

公开仓库前请确认这里不含个人照片或其他隐私素材。
